# Lab3_Algos

1. __str__(self) (метод класса Task) - возвращает строковое представление задачи.

Временная сложность: O(1).

2. __init__(self) - конструктор, создающий пустую очередь.

Временная сложность: O(1) — константное время.

3. enqueue(self, description, priority) - добавляет новую задачу в конец очереди с автоматически вычисленным ID. Размер очереди увеличился на 1. Порядок остальных задач не изменился.

Временная сложность: O(1) — добавление в конец списка.

4. dequeue(self) - удаляет и возвращает первую задачу из очереди, затем перенумеровывает оставшиеся задачи от 1 до N. Первая задача удалена и возвращена. Размер очереди уменьшился на 1. Порядок оставшихся задач сохраняется.

Временная сложность: O(n) — из-за цикла перенумерации (n — размер очереди после удаления) и операции pop(0), которая требует сдвига элементов — тоже O(n). Итого: O(n).

5. front(self) - возвращает первую задачу без удаления. Очередь не изменяется; возвращается элемент self.tasks[0] (или None).

Временная сложность: O(1) — прямой доступ по индексу.

6. isEmpty(self) - проверяет, пуста ли очередь. Возвращает True, если len(self.tasks) == 0, иначе False. Состояние очереди не меняется.

Временная сложность: O(1).

7. display_tasks(self) - выводит все задачи в виде таблицы, а если очередь пуста, выводит "Список пуст" и возвращает None.

Временная сложность: O(n) — итерация по всем задачам.
